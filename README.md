# Gabarito

Folhas de resposta por aluno (PDF e Word), correção pela câmera do celular e notas sincronizadas na nuvem.

- Site: https://andersonserafimcpv.github.io/gabarito/
- Login e banco de dados: Firebase (projeto `gabarito-escolar`), configurado em `js/config.js`.
- Regras do Firestore: `firestore.rules` (cada professor vê só os próprios dados).
